# BasketShop

Projet pédagogique BTS SIO SLAM : adaptation basketball de l'énoncé « Projet Boxe — le site de Sport.com ».

## Pages
- `index.html` : catalogue de quatre ballons, promotions fictives.
- `qui-sommes-nous.html` : histoire, chiffres clés, équipe fictive, adresse et horaires fictifs, carte OpenStreetMap, formulaire de démonstration.
- `css/style.css` : feuille CSS commune et media query à 575 px.
- `images/ballon.svg` : illustration SVG originale utilisée pour les produits.
